# Consultancy Project: Design of Standard Cell Library (SCL 180nm)

-> Designed a full-custom Standard Cell Library (SCL) in 180nm CMOS technology for Struent Semiconductors Pvt. Ltd. using Domino Logic style, developing a comprehensive set of digital logic cells including Inverter, Buffer, AND, OR, AOI, OAI, XOR, XNOR, and Multiplexer.

-> Implemented each logic cell across multiple drive-strength variants (1×, 2×, 4×, and 8×) and created schematic designs, transistor-level layouts, optimized floorplans while adhering to standard cell design methodologies, transistor sizing constraints, and layout optimization techniques for area and performance.

-> Performed DRC and LVS verification to ensure layout-schematic equivalence and foundry rule compliance, delivering a manufacturable and reusable standard cell library.
